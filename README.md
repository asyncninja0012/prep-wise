## <a name="introduction">🤖 Introduction</a>

Built with **Next.js** for the user interface and backend logic, **Firebase** for authentication and data storage, styled with **TailwindCSS**, and powered by **Vapi voice agents**, Prepwise is a platform designed to help users prepare for job interviews with AI-driven mock interviews.  

The platform provides:  
- AI-generated interview questions  
- Real-time AI interview simulations  
- Automated feedback and scoring  
- A modern and responsive UI  

---

## <a name="tech-stack">⚙️ Tech Stack</a>

- Next.js  
- Firebase  
- Tailwind CSS  
- Vapi AI  
- shadcn/ui  
- Google Gemini  
- Zod  

---

## <a name="features">🔋 Features</a>

👉 **Authentication**: Sign Up and Sign In using Firebase Authentication.  
👉 **Create Interviews**: Generate job interviews with Vapi voice assistants and Google Gemini.  
👉 **AI Feedback**: Receive instant performance feedback and scoring.  
👉 **Modern UI/UX**: Clean, user-friendly, and responsive interface.  
👉 **Interview Page**: Conduct AI-driven interviews with transcripts.  
👉 **Dashboard**: Manage and track all your interviews.
